# Environment

## Required runtime

- Node.js 20+ (22 LTS recommended; verified on Node 26)
- pnpm 10
- Docker Desktop or compatible engine (Postgres 16 + Redis 7)
- Optional: local PostgreSQL 16+/Redis 7 if you do not use Docker

## Ports

| Service | Port |
| --- | --- |
| Storefront | 3000 |
| Admin | 3001 |
| API | 4000 |
| PostgreSQL (Docker) | 5433 |
| Redis (Docker) | 6380 |

`5433`/`6380` avoid collisions with common local installs. Update `.env` if you change them.

## Variables

| Variable | Purpose | Required |
| --- | --- | --- |
| `NODE_ENV` | `development` / `production` / `test` | yes |
| `DATABASE_URL` | PostgreSQL connection string | yes |
| `TEST_DATABASE_URL` | Dedicated test database (optional) | no |
| `REDIS_URL` | Redis connection URL | yes |
| `SESSION_SECRET` | Session/token entropy source (use 32+ bytes in production) | yes |
| `PAYMENT_SANDBOX_SECRET` | HMAC key for sandbox webhooks | yes |
| `APP_URL` | Storefront origin (cookies, CORS, Origin checks, links) | yes |
| `ADMIN_URL` | Admin origin | yes |
| `API_URL` | Public API origin | yes |
| `NEXT_PUBLIC_API_URL` | Build-time public API hint (apps use relative `/api`) | no |
| `API_INTERNAL_URL` | Server-side proxy target (Docker: `http://api:4000`) | no |
| `MAIL_MODE` | `file` (default) or `smtp` | no |
| `MAIL_FROM` | From address | no |
| `SMTP_HOST/PORT/USER/PASSWORD` | SMTP credentials when `MAIL_MODE=smtp` | no |
| `PAYMENT_PROVIDER` | `sandbox` | no |
| `SHIPPING_PROVIDER` | `sandbox` | no |
| `RATE_LIMIT_TTL/MAX` | API throttle window and limit | no |

Secrets are git-ignored. `.env.example` contains local-only defaults and must never hold production credentials.

## Env file layout

`node scripts/setup-env.mjs` reads the root `.env` and writes:

- `packages/db/.env` — Prisma CLI
- `apps/api/.env` — API runtime
- `apps/worker/.env` — worker runtime
- `apps/web/.env.local` — storefront
- `apps/admin/.env.local` — admin
- `tests/e2e/.env` — E2E defaults

Rerun after changing root `.env`.

## First-run sequence

```bash
pnpm install
cp .env.example .env
node scripts/setup-env.mjs
docker compose up -d postgres redis
pnpm --filter @dayshift/db generate
pnpm build:packages
pnpm --filter @dayshift/db exec prisma migrate dev
pnpm db:seed
pnpm dev
```

## Data reset

```bash
SEED_RESET=1 pnpm db:seed                 # demo data only
docker compose down -v                    # destroys local volumes
```

Never point the seed reset at a database containing real customer data.
